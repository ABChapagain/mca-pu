
# 📘 MCA PU – Notes, Model Questions & Resources

A complete and organized collection of MCA (Master of Computer Applications) – Purbanchal University study materials.

This repository includes **notes**, **syllabus breakdowns**, **model questions**, **solved numericals**, **lab works**, **PYQs**, **assignments**, and **exam-focused resources** for all semesters.

---


## 📚 Contents

**✔ Notes**

- Unit-wise and chapter-wise summaries
- Important definitions, concepts, and explanations

**✔ Model Questions**
- Teacher-provided model sets
- Past year exam patterns
- 5-mark / 10-mark probable questions

**✔ Numerical Solutions**
- Step-by-step solved numerical problems
- Algorithms, OS, networking, DBMS, AI, and more

**✔ Practical Files**
- Lab manuals
- Sample code
- Project guidelines

**✔ Exam Preparation**
- Short notes
- Most important topics
- Quick revision materials


## 🎯 Purpose

This repository is created to help:
- PU MCA students preparing for exams
- Students needing quick revision materials
- Those who missed classes or need organized study notes
- Anyone looking for previous questions or important topics
